# THE BLACK PAGES — Directory-first UI direction

THE BLACK PAGES is a Black-owned business directory, analogous to a modern White Pages / Yellow Pages utility. It is not an events discovery product.

## Primary user jobs
1. Find a Black-owned business by name, category/service, or location.
2. Browse categories and subcategories.
3. View reliable business contact information.
4. Save a business.
5. Add a Black-owned business.
6. Claim an existing business profile.

## Primary navigation
- Home
- Directory
- Categories
- Saved
- Account

Event-first labels such as Discover, Popular right now, Day Parties, and Events should not drive the UI. Event-only records are excluded from the public directory experience.
